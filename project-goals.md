# Project Goals — Healthcare Analytics (Doctor Visits)

**Dataset:** 5,190 records, 13 columns: `visits`, `gender`, `age`, `income`, `illness`, `reduced`, `health`, `private`, `freepoor`, `freerepat`, `nchronic`, `lchronic` (+ id column).

**Goal:** Follow the "Student-Friendly Dataset Understanding Guide" (screenshots) to analyze what drives doctor visits.

Guide sections to cover:
1. **Dataset Overview** — people, health conditions, healthcare support, doctor visits
2. **Main Objective** — analyze patient info, identify patterns in doctor visits; compare age, health condition, illness, income, chronic conditions, healthcare support vs number of visits
3. **Column Definitions** — what each column represents
4. **Grouping the Columns** — Personal Info (gender, age); Health Info (illness, health, reduced, nchronic, lchronic); Healthcare Support (private, freepoor, freerepat); Doctor Visit Info (visits); Record Identification (id)
5. **Simple Meaning of Healthcare Analytics** — studying healthcare data to find patterns, support understanding & decision-making

**Note:** The inline CSV data must be saved as `healthcare_visits.csv` in this folder before running the analysis.
